# AntiRKN Manager

Flutter GUI для Windows/Linux/Android. Состояние — прототип P0, описанный в [корневом README](../../README.md).

В `Настройки / Settings` доступны системный язык, Русский и English. Ручной выбор сохраняется на этом устройстве. Переводы находятся в `lib/l10n/*.arb`, генерируются штатным `flutter gen-l10n` и используются во всех экранах.

Основной работающий сценарий: «Выбрать YAML-файл» через системный диалог → чтение независимой копии в память → редактирование базового YAML → выбор тестовых имён узлов → проверка состава групп и диагностик. В разделе «Сервер» реализованы SSH-подключение одного VPS Ubuntu 24.04, реальный каталог адресов и постоянное зашифрованное хранилище подключения; публикации ещё не реализованы.

До выбора редактор пуст; исходный файл остаётся без изменений. Отмена/ошибка сохраняет текущий текст. Копия хранится до завершения процесса; после холодного запуска файл выбирается заново.
