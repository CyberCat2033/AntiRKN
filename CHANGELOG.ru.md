# Список изменений

В этом файле описываются заметные для пользователей изменения AntiRKN.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[семантическое версионирование](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- Форма VLESS REALITY: кнопка **«Подобрать»** ищет подходящие target и SNI среди соседей сервера с этого устройства (TLS 1.3, HTTP/2, обмен ключами, проверенный сертификат, DNS), проверяет лучших с самого сервера (3x-ui) с временем от сервера до target, рекомендует лучшие с объяснением, заполняет Target и SNI, умеет останавливаться и продолжать, экспортирует результаты в JSON или CSV. Лучший результат предлагается следующему inbound этого сервера.
- Настройки → «О приложении»: назначение приложения, лицензии (GPL-3.0 и компоненты) и ссылка на исходный код.
- Проект распространяется по лицензии GPL-3.0; добавлены отказ от ответственности (назначение, отсутствие гарантий) и политика безопасности.

### Изменено

- XHTTP-inbound получает сгенерированный путь (вида `/assets/k3x9q2m7wd`) при проверке или выборе target, если путь ещё `/`.
- Кнопка проверки REALITY target теперь называется **«Проверить»**.
- Пакеты для Windows и Linux содержат лицензию и отказ от ответственности; установщик Windows показывает лицензию.
- Настройки: карточка состояния синхронизации теперь единственный вход в «Синхронизацию» и называется так же; дублирующий пункт списка убран.
- README переписан на русском и английском; обновлены руководство пользователя и политика конфиденциальности, в ней перечислены все сетевые адреса, к которым обращается приложение.


## [0.1.1] - 2026-11-28

### Добавлено

- Подписанные обновления приложения из GitHub Releases для Android, Windows и Linux.

### Изменено

- «Настройки → Обновления» теперь управляют обновлением приложения; проверка компонентов серверов всегда включена.

### Исправлено

- После синхронизации с другого устройства сервер, последнюю операцию на котором выполняло то устройство, больше не считается навсегда занятым «другим устройством»: его состояние перечитывается, и приложение перестаёт опрашивать его каждые две секунды.
- Перечитывание серверов после синхронизации дожидается ещё идущего подключения, а не показывает «Подключитесь к этому серверу» до нажатия «Повторить».
- Android: обновления приложения всегда показывались как недоступные.
- Android: после долгого простоя телефона Google Drive мог выглядеть так, будто вход сброшен.

## [0.1.0] - 2026-11-27

### Добавлено

- Первый выпуск: настройка и управление VPS по SSH через службу `antirkn-runner` на Ubuntu.
- Ресурсы VLESS, TrustTunnel и AmneziaWG, клиентские пользователи и сборка профилей Mihomo.
- Зашифрованное локальное хранилище, резервные копии и синхронизация через Google Drive.
